# Instagram Setup-Checkliste — youforge.studio

- [ ] Professioneller Account aktiv (falls nicht)
- [ ] Anzeigename: `YouForge | Digital Studio`
- [ ] Bio Version A einfügen
- [ ] Kategorie setzen (Digital Creator / Agentur)
- [ ] Profilbild: `youforge-instagram-1080.png` (oder extra-margin)
- [ ] CTA-Button aktivieren (E-Mail / WhatsApp / Termin)
- [ ] Kontaktinfos hinterlegen (E-Mail Pflicht)
- [ ] Link-in-Bio setzen (temporär WhatsApp/Calendly, später Website)
