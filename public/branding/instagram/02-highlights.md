# Highlights-Struktur

Ziel: 5 Highlights, die sofort Vertrauen + Orientierung geben.

## Order (links nach rechts)
1. `Vision`
2. `Leistungen`
3. `Prozess`
4. `Ergebnisse`
5. `Kontakt`

## Inhalt je Highlight

### 1) Vision
- Wer ist YouForge
- Slogan: „Wir schmieden deine Vision.“
- Markenwerte (Mut, Lösungen, Zukunft)
- 3–5 Stories

### 2) Leistungen
Je 1 Story:
- Websites
- Landingpages
- KI
- Automatisierung
- Web-Apps
- Beratung

### 3) Prozess
- 1. Gespräch
- 2. Konzept
- 3. Build
- 4. Launch
- 5. Wachstum

### 4) Ergebnisse
- Vorher/Nachher Platzhalter
- Metriken (Ladegeschwindigkeit, Conversion, Automation-Stunden)
- Customer Quotes (sobald vorhanden)

### 5) Kontakt
- CTA: Projekt starten
- Link / WhatsApp / E-Mail
- Was mitbringen zum Erstgespräch

## Cover-Look (Designregel)
- Hintergrund: tiefschwarz `#0B0B0B`
- Icon: weiß oder Lime-Glow
- Kein kleiner Text außer 1 Wort
- Runder Safe-Crop beachten
- Stil: 3D/Universe-Anmutung, dezent

## Cover-Titel (final)
- Vision
- Leistungen
- Prozess
- Ergebnisse
- Kontakt

## Cover-Icons (einfach)
- Vision: Funke / Forge-Zacke
- Leistungen: Grid / Module
- Prozess: Steps / Arrow
- Ergebnisse: Chart / Up
- Kontakt: Arrow Down / Message
