# YouForge Instagram Logo Spec (Final Direction)

## Approved Look
Dieses Logo ist freigegeben als finale visuelle Richtung:

- fused 3D Monogramm: `Y` + `F`
- dunkles Metallgehäuse mit Panel-Lines / Bevels
- Neon-Lime Energiekern als Glow
- Universum-Hintergrund (Sterne, Nebula, Lens Flares)
- cinematic, massiv, future

## Color Intent
- Shell: dunkles Metall / Charcoal / Gunmetal
- Core: Neon Lime Glow
- Atmosphere: Deep Space Schwarz + weiche Nebula

## Usage Rules
1. Profilbild auf Instagram: immer die 1080er Variante.
2. Keine Abflachung auf simple Flat SVG mit Lime-Fill.
3. Website/Hero darf denselben 3D-Stil übernehmen.
4. Lime bleibt Glow/Energie, nicht Hauptflächenfarbe.
