1. Keine flachen 2D-YF-Icons mehr.
2. Immer Space/Universe als Atmosphäre.
3. Lime nur als Energiekern / Glow, nicht als flächige Fill-Farbe.
4. Außenform dunkel, metallisch, detailliert.
